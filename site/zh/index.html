Proofs of Okada's Conjectures 9.63 and 9.64 with constant-base-shift extensions (arXiv:2003.02112v2, Section 9.8.3)

Haobo Ma, Wenlin Zhang

论文

这篇手稿研究：两个相关、各自系数对称的多项式乘积相减后，删去零系数，剩余序列还能否对称？Haobo Ma 与 Wenlin Zhang 证明，在基本的无移位情形中，符合条件且因子数至少为三的构造都不具备这种对称性；只有两个因子时，它成立恰好等价于两个指定间隔中至少一个为一。

基本对象是二项式系数的多项式版本，称为高斯二项式多项式，系数正读、倒读相同。例如，上指标为 n、下指标为一时，它是 1 + q + ⋯ + qⁿ⁻¹。选两列等长的非负整数，各列严格递增，第一列最大项不超过第二列最小项；列长叫宽度。以对应项为下、上指标，得到乘积 A；颠倒第一列再配对，得到 B。研究对象为 P = A − B，问题是相减后还剩多少对称性。

“几乎回文”指删去全部零系数后，序列正反相同。作者解决了 So Okada 在2024年1月版本中提出的两个猜想：宽度至少为三时，P 的前两个非零系数为一和 c + 1，最后两个为 c 和一，其中 c 是 A 中非常数因子的个数。删零无法消除差异。例如，两列取 (0,1,2) 和 (2,3,4)，非零系数为 (1,3,4,4,2,1)，三与二就阻止了回文性。

证明只比较两端。把高斯多项式写成由 1 − qʲ 组成的乘积之比，在 B/A 中约去共同因子。低次部分几乎全部相消，留下的两个因子决定相消何时停止，迫使第二个非零系数为 c + 1。另一端，A 的系数对称，且次数至少比 B 高四，所以减去 B 不影响末尾的 c 和一。作者还保证比较位置确实不同，无须计算中间全部系数。

宽度为二时，两个间隔分别是各列两项之差。若都至少为二，同一障碍成立；若至少一个为一，进一步约分得到整个有效次数区间的对称性。固定最大项为整数 λ ≥ 2，按间隔与偏移量计数，非几乎回文者的比例为 O(λ) = (λ − 2)(λ − 3)/(λ(λ + 1))，从 λ = 3 起严格递增，趋于一。但两列 (0,1) 和 (m,n)，其中 1 ≤ m < n，会产生初始零项后连续的一串系数一，给出无穷多个几乎回文且单峰的例子；单峰指系数先不降、后不升。

恒定正整数“基移位”既改变高斯因子，又附加多项式因子，并非简单地对 P 作变量替换。次数移位为零时，B/A 和次数差不变，分类与计数因而适用于所有恒定基移位。相反，把修改后的两个乘积各取同一个至少为二的整数次幂再相减，任何至少为二的宽度都不再几乎回文：首个非零系数等于该指数，末项却为一。

另一个参数是次数移位 e，只给 B 乘上 qᵉ。令 G 为正向乘积次数减去反向乘积次数；Okada 的后续猜想问，宽度至少为三且 0 ≤ e ≤ G 时，改变恒定基移位是否保持几乎回文性。本文仅证明 e = 0、1、G − 1、G，以及 G 为偶数时的 G/2。前四种均非几乎回文；倒转系数交换 e 与 G − e，中点则对称。宽度二不同：作者推广 Okada 的旧例，取 (0,1)、(1,n)，n ≥ 4，且 e = 1；基移位从一增至任意更大整数，几乎回文性便消失。n = 4 时原多项式为 1 + q² + q³，须删零才回文。这不反驳宽度至少为三的猜想。

手稿报告了精确计算：最大项不超过十、宽度三至六的1486例，以及最大项不超过十八的4845个宽度二例。这些有限计算补充而不代替全参数书面证明。据作者说明，Lean 证据只覆盖单位基移位、单位权重、零次数移位、宽度至少为三的结论及端点系数，不包括宽度二分类、计数或扩展。意义在于用端点解释不对称，并完整分类两个因子的情形。基移位不变性猜想的其他次数移位仍未解决。更广泛的单峰性问题，以及要求每项系数的平方不小于相邻两项乘积的对数凹性，也未由本文论证解决。
